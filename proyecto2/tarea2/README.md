## Avance de MATLAB

El código está en [matlab/](matlab/README.md). Para comenzar, abrir esa carpeta en MATLAB y ejecutar `ejemplo_ideal`. El ejemplo ideal fue ejecutado por el usuario y recupera los parámetros hipotéticos esperados. El análisis con mediciones reales y la función `impulse` con Control System Toolbox siguen pendientes. Las gráficas simuladas no sustituyen los datos ni el video exigidos para el punto extra.
